Pour chaque cadence, je calcule la durée d'une image, puis je soustrais 8 ms 



À 72 Hz

Durée de l'image = 1000 / 72 = 13,889 ms

&#x20;= 13,889 - 8 = 5,9 ms



À 90 Hz

Durée de limage = 1000 / 90 = 11,111 ms

= 11,111 - 8 = 3,1 ms



À 120 Hz

Durée de l'image = 1000 / 120 = 8,333 ms

= 8,333 - 8 = 0,3 ms
